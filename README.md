# 💊 Бот-нагадувач про прийом ліків

Telegram-бот на Python, який нагадує про прийом ліків за розкладом.

## Можливості

- **➕ Додати ліки** — назва → до/після їжі → скільки разів на день → перший і останній прийом (кнопками або вручну, напр. `7:30`). Проміжні прийоми розподіляються рівномірно автоматично (з округленням до 5 хв). Опційний коментар показується в кожному нагадуванні.
- **✏️ Редагувати** — змінити назву, до/після їжі, час або коментар.
- **🗑 Видалити** — з підтвердженням.
- **⏸ Зупинити всі нагадування** — з кнопкою «▶️ Відновити всі».
- **🌐 Соцмережа автора** — посилання з `AUTHOR_URL`.
- Кнопка **✅ Прийнято** під кожним нагадуванням.

### Лікар → пацієнт

При додаванні оберіть «👥 Для іншого користувача» і введіть ID або @username пацієнта.

- Пацієнт **обов'язково** має спершу запустити бота (`/start`) — це обмеження Telegram: бот не може першим написати людині.
- Свій ID пацієнт бачить після `/start` або командою `/myid`.
- Пацієнт отримує повідомлення про призначення та нагадування; лікар — сповіщення, коли пацієнт натискає «✅ Прийнято».
- Обидва бачать це нагадування у своїх списках і можуть редагувати/видаляти.

## Запуск

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

Вкажіть у `.env` токен від [@BotFather](https://t.me/BotFather) та посилання на соцмережу, потім:

```bash
python bot.py
```

Дані зберігаються в SQLite (`meds.db`); після перезапуску всі нагадування відновлюються автоматично.
Команди: `/start`, `/myid`, `/cancel`.
